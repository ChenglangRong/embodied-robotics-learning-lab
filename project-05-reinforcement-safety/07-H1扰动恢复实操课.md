# H1双足扰动恢复实操

本课目标是在已标定的站姿上，让 H1 承受一次水平推力并恢复双脚支撑。按观察回放、解释控制链、核对一帧、修改增益、验收的顺序学习。场景为平地小初态扰动，控制器采用解析反馈，RL 训练次数为 0。

## 实验面板与仿真顺序

先播放[同种子并排仿真](outputs/h1-demo-20261122/strong-front-gain-pair.gif)。左侧 Kc=12，右侧 Kc=6，均使用种子 3000014。顶部力值对应最近一个 20 ms 区间。看第 2.9 秒，两边都是双脚接触，左侧质心前向误差约 +4.2 cm，右侧约 +1.9 cm。再用原始轨迹检查两个回合何时持续满足误差、速率和双脚支撑条件。

双击 `open_h1_lab.cmd`。已有项目02 Python 环境和项目03固定模型可直接复用。面板的“实时3D”读取右栏参数，“载入保存回放与指标”读取当前保存目录，指标页显示该目录实际使用的增益。

1. 选择 `com / strong_front / 3000000`，加载保存回放，点击播放。在 GIF 角落读取时间、推力、质心误差和踝修正。第 2 秒施力，2.2 秒撤力。切到指标页，看同场景五个种子的结果。
2. 在相同种子下改选 `fixed / strong_front`。保存回放约 1.4 秒就结束，此时推力窗口尚未开始。用实时3D再比较 `fixed / none` 与 `com / none`，检验站立基线。`none` 的全部指标存在，视觉演示走实时3D入口。
3. 用 `com / push_left` 观察受侧推的姿态和侧向质心误差。用 `com_no_damping / none` 观察去掉速率项后的摆动和饱和，用 `wrong_sign / none` 核对反号后误差扩大的方向。
4. 将位置增益 Kc 从 12 改成 6，速率增益保持 2.4。点击“实时3D”做可见试跑。点击“五种子全对照”可生成一套新实验和日志，存入 `outputs/h1-student/`。固定种子的新实验适合试错，正式个人对照用下文命令指定一组新种子。

四个保存 GIF 覆盖 `fixed` 和 `com` 的 `strong_front` 与 `push_left`，均用种子 3000000。所有 100 个冻结回合都能从原始轨迹查看，即便当前组合没有 GIF。

## 知识卡 1　什么在恢复

拿一根扫帚立在手掌上。扫帚向前倾时，你把手掌移到扫帚下方，才能改变它接下来倾倒的方向。H1 的脚掌在固定支撑实验中留在地面，踝关节力矩通过脚地接触改变地面合力，从而影响身体运动。质心 CoM 是各部件位置的质量加权平均，代码读的是骨盆子树质心。脚下压力中心 CoP 是地面接触力的等效作用位置，本课的踝中点是几何参考。身体已经有水平速度时，单看这一帧的质心位置会漏掉下一刻的运动趋势。

可用恒定质心高度的线性倒立摆建立直觉。忽略质心角动量变化时，近似关系为 `ẍ = (g/h)(x − p)`，其中 `h` 是质心高度，`p` 是地面压力中心。`p` 在 `x` 前方时，近似加速度向后。H1 仿真直接积分多体动力学与接触，控制器的反馈变量和验收指标从仿真状态读取。[Kajita 等的线性倒立摆说明](https://www.cs.cmu.edu/~cga/ew/kajita-icra02.pdf)

## 知识卡 2　站姿与扰动分开检查

参考为骨盆高 1.06279 m、髋俯仰 −0.20 rad、膝 0.45 rad、踝 −0.25 rad。这组数用于指定模型与碰撞几何。课内复算从 `reset()` 读无噪声的参考，再用 MuJoCo 正向运动学检查两只脚的碰撞体与地面之间的距离。关节夹角只确定部分几何信息，足底高度还取决于模型的关节原点、局部变换和碰撞体尺寸。标定值允许带小高斯重置噪声，接触验收读实际采样。

50 Hz 控制每 20 ms 更新一次参考，每步进行 10 次 2 ms 物理积分。外环 0.3 秒启用，2.0 秒开始推力，2.2 秒撤力。`xfrc_applied` 将世界坐标中的力施加在骨盆刚体质心，施加的外力矩为零。`none`、`push_front`、`strong_front`、`push_back`、`push_left` 对应零力、+40 N x、+60 N x、−60 N x、+120 N y。前向 60 N 的冲量为 12 N·s，侧向 120 N 为 24 N·s。冲量等于外力对时间的积分，机器人速度响应还受接触反力影响。[MuJoCo 数据类型](https://mujoco.readthedocs.io/en/3.2.5/APIreference/APItypes.html) · [外力作用点](https://mujoco.readthedocs.io/en/3.2.0/computation/index.html)

## 知识卡 3　位置修正和速率项

`measure()` 以世界坐标测量 `e_x = CoM_x − 踝中点_x − 0.05 m`，侧向误差为 `CoM_y − 踝中点_y`。采用 `e_f ← e_f + 0.15(e_x − e_f)` 平滑前向误差。速率输入 `v_x` 取 `d.qvel[0]` 的骨盆前向速度，历史字段 `com_rate_x_m_s` 沿用旧名称。这个量是误差速率的代理，严格计算质心相对支撑点速度需要质心速度减去支撑参考点速度。

`reference_correction()` 计算 `Δq = Kc · e_f + Kr · v_x`，两踝同步加入这个修正，`q_ankle = −0.25 + Δq`。名义 Kc = 12 rad/m，Kr = 2.4 rad·s/m。`step()` 内层用关节 PD 加动力学偏置力 `qfrc_bias` 算控制，再按执行器范围限幅。位置项推动误差回到目标，速率项帮助制动。本模型的踝参考偏置试验记录了负的前向加速度斜率。符号迁移到另一台人形机器人时要重新测量。

| 控制器 | 外层参考修正 | 可检验的问题 |
| --- | --- | --- |
| `fixed` | 0 | 固定关节参考可以站多久 |
| `com` | `Kc·e_f + Kr·v_x` | 外环能否建立并维持站姿 |
| `com_no_damping` | `Kc·e_f` | 保留位置项时，去掉速率项的效果 |
| `wrong_sign` | `−(Kc·e_f + Kr·v_x)` | 这一站姿和模型下的反馈方向 |

这四组共用内层 PD、模型和设定的推力时序。许多消融组在 2 秒前就结束，其成绩直接反映站立能力，推后恢复需要先从日志确认这些回合确实受到推力。侧推结果反映整套双脚接触和控制的综合表现，代码中的外环仅修正矢状面踝角。

## 知识卡 4　手算和逐帧核对

若滤波误差 `e_f = +0.03 m`、骨盆前向速度 `v_x = −0.02 m/s`，则 `Δq = 12×0.03 + 2.4×(−0.02) = 0.312 rad`，踝参考为 `0.062 rad`。同样输入下改成 Kc = 6，`Δq = 0.132 rad`，踝参考为 `−0.118 rad`。这些是参考角。实际扭矩还取决于关节误差、速度、动力学偏置与限幅。

代码顺序从 `reset → measure → reference_correction → step → assess` 读。每行时间是积分后的时间，力和参考属于上一控制区间，速度属于积分后状态。用当前行的滤波误差和**上一行**的骨盆速度重算当前行的踝修正。例如 `Kc=12 / strong_front / 3000014` 的 2.22 s 行，当前滤波误差 0.0169820067 m，前一行速度 0.1700253883 m/s，得到 `Δq≈0.6118450121 rad`。2.22 s 行的推力为 0 N，这一行覆盖撤力后的首个区间 `[2.20, 2.22]`。

## 编程实操　只改位置增益

先预测 Kc = 6 会怎样改变峰值位移、撤力后稳定时间和末端误差。在测试文件添加一条位置增益为 6 的手算断言，运行 `test_h1_recovery`。下面两次运行共享新重置种子、推力、模型、速率增益和判据。把命令中的运行目录换成自己尚未使用的目录。`--no-render` 生成完整轨迹而且省去 GIF 渲染。

```powershell
# 仓库根目录，复用项目02的 Python 环境。
$H1Py = './project-02-urdf-mujoco-ros2/.venv/Scripts/python.exe'
$H1Dir = 'project-05-reinforcement-safety'
$H1Out = "$H1Dir/outputs/h1-student"
$H1Seeds = 3000020,3000021,3000022,3000023,3000024
& $H1Py "$H1Dir/h1_recovery.py" --output "$H1Out/pair12" --controllers com --com-gain 12 --com-rate-gain 2.4 --seeds $H1Seeds --no-render
& $H1Py "$H1Dir/h1_recovery.py" --output "$H1Out/pair6" --controllers com --com-gain 6 --com-rate-gain 2.4 --seeds $H1Seeds --no-render
& $H1Py "$H1Dir/verify_h1.py" "$H1Out/pair12" --output "$H1Out/pair12-replay.json"
& $H1Py "$H1Dir/verify_h1.py" "$H1Out/pair6" --output "$H1Out/pair6-replay.json"
& $H1Py "$H1Dir/compare_h1_gains.py" "$H1Out/pair12" "$H1Out/pair6" --output "$H1Out/paired.json"
& $H1Py "$H1Dir/render_h1_pair.py" "$H1Out/pair12" "$H1Out/pair6" --seed 3000024 --output "$H1Out/strong-front.gif"
```

阅读 `paired.json` 的 `by_scenario`，再选择一个种子从 `pairs` 追溯到 `trajectories.jsonl.gz`。双脚接触按有超过 1 N 法向力的足地接触采样，记录滑移和饱和用于定位代价。教学示范用的 3000010–3000014 可直接对照其公开运行结果。[配对实验记录](实验记录-H1扰动-20261016.md#2026-11-22-同种子位置增益对照)

## 机器验收与个人验收

| 核对项 | 如何检查 |
| --- | --- |
| 姿态和完整性 | 300 步、全回合直立且状态有限、骨盆高度 ≥ 0.62 m、最大绝对俯仰或横滚 ≤ 0.55 rad |
| 回到误差带 | 恢复段 `|e_x| ≤ 0.035 m`、`|e_y| ≤ 0.03 m`、骨盆水平速率范数 ≤ 0.12 m/s，冻结恢复时间 ≤ 2.5 s，末段满足冻结稳定条件 |
| 足地接触 | 从 2.0 s 起每个采样保持双脚接触，平均接触点水平滑移 ≤ 0.25 m/s |
| 扰动真的发生 | 冻结判据中的 `pushed_by` 检查场景设定，实际施力由日志逐步核对。非零场景需要连续 10 条施力记录，`ΣF·Δt` 应等于相应冲量 |
| 撤力后稳定时间 | 以 2.2 s 为零点，查找回合末尾持续在误差带且保持双脚支撑的区段。该段至少覆盖 0.4 s，区段首样本与 2.2 s 之差为教学指标。`none` 以名义撤力时刻作为对照 |

冻结评分从推力开始后 0.5 s 以上才登记恢复，所以常见 0.52 s 表示命中评分下界。配对报告增加撤力后稳定时间，保留两种结果。饱和比例是任一执行器被限幅的物理子步占比，属于诊断量。软件回放逐步核对浮点轨迹和离散字段，容差及最大差异随核验报告保存。

个人验收交四件证据：运行前预测、自己的测试或代码修改、同种子的 Kc 对照、一个回合的时序解释。解释中指出支撑和误差带何时满足，给出一个改善和一个代价。使用 [个人实验记录模板](../project-03-robot-platforms/个人实验记录模板.md)。

## 迁移到具身智能

把恢复控制作为移动或操作技能的低层接管模块。上层可提交目标和接管条件，低层按控制周期处理接触与力矩。行走时支撑区域随脚步改变，踏步恢复还要评估落脚可达性和支撑切换。本课的双脚固定支撑指标可作为对照。高层 GPT 技能规划、π0.5 动作接口与低层恢复各有验收，本课模型推理次数为 0。下一平台 Allegro 将用类似的接触证据判断物体滑移与抓持恢复。
