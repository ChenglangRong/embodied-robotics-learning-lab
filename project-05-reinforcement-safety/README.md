## 冻结实验

`outputs/baseline-20261013/` 保留五种子 Q 表、访问次数、每回合训练日志、全起点评测、已知模型最优解、曲线、GIF、失败、配置、源文件快照与哈希清单。`outputs/verification-20261013.json` 为保存策略的独立重新执行报告。

固定目标、21×21关节网格、5个离散动作、4.5 cm容差、80步外部采样预算；训练每种子6000回合。评测穷举同一 MDP 的440个非终点起点，训练可以访问这些状态。改变目标是另一个 MDP，单独记录迁移失败。此阶段对应运动学仿真；惯性、接触、碰撞和实机安全在后续物理实验验收。

动作投影保证本离散模型的关节值留在设定网格内；过滤器绕过对照公开保留。训练采用有限预算、固定学习率和有限探索；收敛定理的渐近条件列在知识卡中。

本项目源码为 AI 辅助实现，工具执行训练与验证；学习者自报、个人代码修改和独立验收分别登记。五平台当前/计划范围见 [进阶任务](02-五平台进阶任务.md)。
