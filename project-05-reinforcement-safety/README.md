## 直接操作

双击 `open_lab.cmd`，点“载入公开基线”，从状态210开始点“执行一步”，或点“播放 / 暂停”。左侧机械臂、目标、动作价值表、奖励和终止信息同步变化。点“未训练 Q”再运行相同起点，观察对照。起点0保留已训练策略的失败；点“学习一步”会探索并更新内存副本，公开权重保持冻结。

面板支持新种子训练、回合数输入、结果目录、曲线和停止。新运行保存在 `outputs/student/`，当前公开交付采用精选冻结基线。个人实验在后续交付时连同解释、源码修改和失败证据整理上传。

新机器：Python3.12，运行 `setup.ps1` 后双击入口。本地已有项目02环境可直接复用。

```powershell
& .\.venv\Scripts\python.exe -m unittest test_tabular_lab -v
& .\.venv\Scripts\python.exe tabular_lab.py --output outputs/my-run-001 --episodes 6000 --seeds 0 1 2 3 4
& .\.venv\Scripts\python.exe verify_run.py outputs/my-run-001 --output outputs/my-verification.json
```

输出目录使用新名称，已有证据保留原样。核心源码为 `tabular_lab.py`；GUI 为 `panel.py`；核验为 `verify_run.py`。

## 冻结实验

`outputs/baseline-20261013/` 保留五种子 Q 表、访问次数、每回合训练日志、全起点评测、已知模型最优解、曲线、GIF、失败、配置、源文件快照与哈希清单。`outputs/verification-20261013.json` 为保存策略的独立重新执行报告。

固定目标、21×21关节网格、5个离散动作、4.5 cm容差、80步外部采样预算；训练每种子6000回合。评测穷举同一 MDP 的440个非终点起点，训练可以访问这些状态。改变目标是另一个 MDP，单独记录迁移失败。此阶段对应运动学仿真；惯性、接触、碰撞和实机安全在后续物理实验验收。

动作投影保证本离散模型的关节值留在设定网格内；过滤器绕过对照公开保留。训练采用有限预算、固定学习率和有限探索；收敛定理的渐近条件列在知识卡中。

本项目源码为 AI 辅助实现，工具执行训练与验证；学习者自报、个人代码修改和独立验收分别登记。五平台当前/计划范围见 [进阶任务](02-五平台进阶任务.md)。
