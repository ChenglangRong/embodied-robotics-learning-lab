# Go2速度与转向反馈实操

本课把已有对角步态扩展为速度与转向命令控制。学习顺序：观察相同命令的四控制器对照 → 读身体坐标速度和偏航角速度 → 手算步幅反馈 → 追踪IK与PD代码 → 修改一个因素 → 用完整轨迹验收。当前为解析反馈工程基线，强化学习训练次数为0；Go2学习残差、地形和推力恢复另设实验。

## 本地操作顺序

双击 `open_go2_lab.cmd`。已有项目02环境与项目03固定模型可直接复用；新电脑先按项目03setup准备Menagerie模型，再按项目05setup安装依赖。面板左侧分别提供真实物理回放和命令响应曲线，右侧选择控制器、场景、重置种子与反馈增益。模型固定提交为 `0059d4335f8156206f63a35662313385f7ad6d74`，许可文本保留在项目03licenses。

1. 选择 `fixed`、`left`、种子1000000，点“实时3D · 当前选择”。固定步态继续向前，检查身体朝向与左转命令的差距。
2. 保持场景和种子，改为 `feedforward`，再改为 `feedback`。观察左右步幅差如何产生偏航，比较曲线中的命令、原始响应与0.5秒均值。
3. 改为 `fast`，比较前馈与反馈的速度误差；再运行 `slow`，观察增益在不同速度区间的影响。
4. 改为 `step_stop`，看0—3秒0.08m/s、3—6秒0.16m/s、6秒后零命令。反馈控制进入站立模式，固定步态继续运动。
5. 最后运行 `wrong_sign`，把它作为独立失败对照，读取速度误差、滑移与步幅限幅次数。反号反馈的仿真实验按失败保留，实机接入需专门安全流程。

“载入保存回放与曲线”固定使用种子1000000，覆盖fixed/feedback的fast、left和step_stop。实时3D支持全部四控制器、五场景和五重置种子；增益输入只作用于实时或新实验。面板支持暂停、停止并保留日志、五种子新实验和原始结果查看。每次运行包括2秒站立准备与最多10秒实验，学习时间按个人掌握程度分配。

## 知识卡1 命令与身体坐标

本课命令为前进速度 `v_cmd`，单位m/s，以及绕世界竖直轴的偏航角速度 `ω_cmd`，单位rad/s。机器人身体x轴指向前方，身体y轴指向左侧；前进速度在身体坐标系读取，转向后仍沿身体前方定义。世界速度通过 `v_body=Rᵀv_world`转换，R把身体向量旋转到世界。举例：身体已左转90度，世界+y方向1m/s对应身体+x方向1m/s。

`mj_objectVelocity`返回旋转速度和线速度，当前代码取后三维为世界线速度并做坐标转换，取前三维中的世界z分量为偏航指标。身体倾斜时，世界z角速度与Euler yaw导数存在差异；当前平地小倾角范围和跌倒阈值随结果记录。坐标系、对象和单位匹配后再计算误差。[MuJoCo官方接口](https://mujoco.readthedocs.io/en/3.2.5/APIreference/APIfunctions.html#mj-objectvelocity)

## 知识卡2 对角步态

四腿顺序FL、FR、RL、RR，分别为左前、右前、左后、右后。相位差采用 `[0,π,π,0]`，让两组对角腿交替摆动，基础频率1.8Hz。足端前后轨迹使用正弦，摆动段抬脚高度70mm，站立腿通过接触摩擦支撑身体。初始1.5秒平滑增加步态幅度，使参考从站立状态逐步过渡。

## 知识卡3 前馈怎样把命令变成步幅

先用几何近似求每条腿对应的前后速度：`v_i=v_cmd−ω_cmd*y_i`。左右近似横向力臂为±0.095m，正偏航命令使右侧步幅大于左侧。再用 `A_i=0.45s×v_i`转换为米制步幅，0.45s是本教学控制器的标定系数。该映射保留简化步态和接触假设，实际速度由伺服、支撑相位与摩擦共同决定。

算例：`v_cmd=.12m/s, ω_cmd=.25rad/s`，左侧速度参考为.09625m/s，右侧为.14375m/s。前馈左步幅43.3125mm、右步幅64.6875mm。你应能从坐标关系解释左右差值的符号，再在 `stride_reference()`核对结果。

## 知识卡4 负反馈修正

误差为 `e_v=v_cmd−v_filtered`、`e_ω=ω_cmd−ω_filtered`，修正后速度参考为 `v_eff=v_cmd+K_v e_v`、`ω_eff=ω_cmd+K_ω e_ω`。默认两个增益均为2，然后沿相同前馈映射生成四腿步幅。实际速度高于命令时，前进修正变小；实际左转不足时，左右步幅差增大。误差修正、步幅限幅、接触与速度测量构成完整闭环。

手算：命令(.12,.25)，滤波测量(.10,.10)，修正后为(.16,.55)。左步幅48.4875mm、右步幅95.5125mm；右侧请求随后进入90mm限幅与变化率约束。这个例子同时检查米、秒、弧度和左右腿顺序。

## 知识卡5 四种控制器的权限

| 控制器 | 步幅来源 | 用途 |
| --- | --- | --- |
| fixed | 四腿固定55mm | 原固定步态参照，命令变化作为测试输入 |
| feedforward | 命令映射 | 检查命令条件化带来的变化 |
| feedback | 命令加测量误差反馈 | 与前馈做匹配对照 |
| wrong_sign | 命令减误差反馈 | 压力测试反馈符号 |

四者共用模型、IK、关节PD、力矩限幅、步幅限幅和同一重置种子。命令条件化控制器在零命令下切换站立参考，fixed继续原步态。比较feedback与feedforward时，状态反馈是主要变化；比较fixed时，还包含命令权限和停步模式的差异。增益为0时，feedback应与feedforward生成相同参考，测试覆盖这个关系。

## 知识卡6 测量滤波与评价平均

反馈使用指数滤波 `v_f←v_f+0.12(v−v_f)`，控制周期20ms，对速度和偏航分别执行。评价另记录过去25样本的0.5秒滑动平均，窗口接近本步态周期，便于观察低频命令跟踪。原始RMSE仍单独保留，并设置振荡阈值；图中同时显示命令、原始值与均值。滤波提供平滑信号，也引入延迟，大增益叠加延迟可能产生振荡。

一个明确反例：慢速场景中，前馈周期均值RMSE约0.0096m/s，默认反馈约0.033m/s。反馈在快速命令与停步中改善较大，慢速标定点的误差反而增加。调参应覆盖多个命令，分别报告偏差、振荡和动态过渡。增益调度、积分项和滤波优化需要独立单因素实验。

## 知识卡7 IK与关节PD

足端前后位置由步幅乘正弦获得，高度由站立高度与摆动抬脚共同生成。每腿采用近似双连杆矢状面IK计算髋俯仰与膝关节，髋外展保留名义参考。十二关节PD计算 `τ=Kp(q_ref−q)−Kd*q̇`，默认Kp=100、Kd=3.5，随后按模型控制范围限幅。每20ms控制步执行10个2ms物理积分步，位置与速度由物理引擎更新。

本控制器保留简化几何、固定频率和关节PD，全身协调与接触力分配需要后续控制课。步幅每轴最多90mm，每控制步变化最多2mm。力矩饱和、身体高度/倾角和足地接触分别监测，参考层限幅的能力边界按轨迹判断。

## 知识卡8 停止需要模式设计

开发标定曾出现零命令后仍输出反馈步幅，机器人持续产生参考摆动，停止段误差过大。当前命令条件化控制器在零命令下把四腿步幅请求置零，并停止抬脚，再通过变化率限制回到站立参考。同一开发种子的停步实验随后通过，原失败轨迹保留在calibration目录。后续可以研究更平滑的步态停止相位和支撑切换，继续监测接触与制动距离。

## 知识卡9 滑移和跌倒

有效足地接触采用法向力>1N阈值。接触点速度由足部几何中心线速度加上 `ω×(p_contact−p_geom)`得到，再读取水平速度范数；它比只观察足端中心更贴近接触滑移。身体高度<.18m、倾角>.75rad或状态数值失效会触发跌倒终止。滑移小、始终站立、速度跟踪与转向跟踪各自有判据，记录中分别读取。

## 知识卡10 指标与验收

| 条件 | 冻结判据 |
| --- | --- |
| 完整运行 | 500控制步，共10秒 |
| 姿态 | 全回合高度≥.18m、倾角≤.75rad、状态有限 |
| 周期均值速度 | RMSE≤.07m/s |
| 周期均值偏航 | RMSE≤.18rad/s |
| 原始振荡 | 速度RMSE≤.2m/s、偏航RMSE≤.5rad/s |
| 足地滑移 | 有效接触点水平速度均值≤.20m/s |
| 饱和 | 出现力矩限幅的积分子步比例≤10% |

评价窗口从实验第2秒开始；变速停止场景额外排除3—4秒、6—7秒的过渡段，完整原始轨迹始终保存。七项同时满足才通过；这些阈值针对平地入门反馈基线，精确轨迹和复杂地形另设任务。开发使用种子0，最终五留出重置1000000—1000004与其分开。重置包括XY、关节和水平速度小扰动，2秒预站立消除了大部分差异，因此当前种子结果相近，支持范围限定于这些平地配置。

## 编程实操与个人验收

打开 `go2_feedback.py`，按 `command → measure → stride_reference → step → assess`标出坐标系、单位和控制周期。在CSV或gzip轨迹中核对一个时刻的命令、滤波值、请求步幅、执行步幅、十二关节参考、实际角度与力矩。先手算上面的左右步幅，再解释 `wrong_sign`误差为何被放大，以及姿态正常仍可能跟踪失败。软件测试覆盖坐标旋转、符号、零增益、零命令站立、重置、滤波记录、周期和力矩限制。

个人修改优先选择一个增益。先保存对慢速/快速/左转/右转/停止五场景的预测，在面板把Kv从2改为1，保持Kω=2，点“运行新实验 · 五种子全对照”。比较各场景原始与均值RMSE、失败条件、滑移、饱和、过渡段和参考干预，记录收益与代价。新实验目录与公开基线分开；正式个人评测追加新的留出重置，保持成功判据和预算固定。

```powershell
# 仓库根目录；已有项目03固定模型，Python路径按安装环境替换。
& ./.venv/Scripts/python.exe project-05-reinforcement-safety/go2_feedback.py --output project-05-reinforcement-safety/outputs/my-go2-001 --velocity-gain 1 --yaw-gain 2 --seeds 1000010 1000011 1000012 1000013 1000014
& ./.venv/Scripts/python.exe project-05-reinforcement-safety/verify_go2.py project-05-reinforcement-safety/outputs/my-go2-001 --output project-05-reinforcement-safety/outputs/my-go2-verification.json
```

公开实验为100案例，包含全部成功和失败的完整状态/控制轨迹；源码、依赖、配置、模型资源哈希、种子、GIF、CSV和均值曲线随记录保留。个人交付沿用 `个人实验记录模板.md`，提交自己的代码修改、闭卷解释和单因素对照；学习自报与独立验收分别登记。
