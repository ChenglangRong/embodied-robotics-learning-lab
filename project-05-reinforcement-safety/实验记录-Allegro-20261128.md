# Allegro 抗滑和局部重定向实验记录

2026-11-28。学习者自报 H1 扰动恢复课程完成。Allegro 学习进行中，个人代码修改和独立验收待提交。此处记录 AI 辅助实现、MuJoCo 实际运行、失败及复现证据。

## 方法与配对

沿用固定版本的 Menagerie Allegro 右手和项目03的球形物体 MJCF，模型提交与逐文件哈希见 [protocol.json](outputs/allegro-20261128/protocol.json)。保留项目03的模型许可证。球质量 40 g、半径 40 mm。掌面可承载，托盘移除。评估期间腕部为固定 mocap 夹具。共同准备 9 秒，评估时间 4 秒，包含 200 控制步、2,000 物理子步。55 个评估回合合计 11,000 控制步、110,000 评估物理子步，另有 247,500 准备物理步。强化学习训练、实机运行与 GPT/π0.5 调用均为 0。

开发用种子 0、11、12。冻结评测用五个独立重置种子 5000000–5000004，球初始 XY 各 ±1 mm、各指关节初角 ±4 mrad。保持组、反馈组共享相同力时序和初态。重定向组共享相同目标、零外力和同一控制时序，唯一改动为拇指近端单关节的参考轨迹。17 N 是同一物体和接触配置下的加压场景。

## 实测结果

| 任务 | 控制器通过数 | 回合指标 |
| --- | --- | --- |
| 零侧拉 | 保持 5/5，反馈 5/5 | 两组平均峰值侧移 4.96 mm，显示自然漂移 |
| 9 N 侧拉 | 保持 5/5，反馈 5/5 | 平均峰值侧移 11.84 → 6.94 mm |
| 13 N 侧拉 | 保持 0/5，反馈 5/5 | 平均峰值侧移 16.81 → 9.94 mm |
| 17 N 侧拉 | 保持 0/5，反馈 0/5 | 平均峰值侧移 21.94 → 15.56 mm，两组均超过 14 mm 阈值 |
| 局部 20° 目标 | 保持 0/5，正向 5/5，反向 0/5 | 最后 0.5 秒的跨回合最坏目标误差分别为 21.58°、0.97°、44.67° |

全部 55 个回合的状态和指令保留，含 25 个失败。反向组平均转了约 24.62°，并出现多指承载条件失败。这表明旋转幅度需要配合目标轴和接触验收。开发种子 0 试过四指同时增加弯曲，整体偏移反而增长。试过 +Z 方向 9 N 以上的开发拉力时球被拉离，冻结试验采用 +Y 方向，保留 17 N 的失败轨迹。13 N 和 17 N 属于指定仿真压力条件。
