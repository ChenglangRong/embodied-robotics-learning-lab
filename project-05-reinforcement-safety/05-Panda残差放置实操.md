# Panda机械臂残差放置实操

本课学习目标：解释名义控制与残差的组合，沿代码追踪笛卡尔参考到七关节伺服，运行真实接触仿真，用匹配对照检验放置能力。学习顺序为看完整抓取搬运 → 比较目标变化下的放置 → 理解观测与控制 → 修改一个因素 → 提交个人验收。本课使用状态输入、固定姿态、XY残差和预设释放时序；视觉感知、自主阶段切换与六维接触技能按后续项目实现。

## 本地操作

双击 `open_panda_lab.cmd` 打开桌面面板。已有项目02Python环境与项目03模型缓存可直接复用；新机器先按项目03 `setup.ps1`准备固定Menagerie模型，再运行项目05 `setup.ps1`。上游Panda模型为Apache2.0许可，仓库 `project-03-robot-platforms/licenses/franka_emika_panda.LICENSE`保留许可文本。模型固定提交、资源哈希、协议与种子写入公开结果目录。

1. 点“载入抓取搬运前缀回放”，再点“回放播放 / 暂停”。看到机械臂接近橙色方块、下降、夹紧、抬升并搬到桌子另一侧；前缀时段0—9秒由原控制器完成。
2. 选择 `zero`、`test`、案例0，开启过滤，点“实时3D · 所选目标放置”。观察新绿色目标与原放置位置的差距；窗口结束后从结果日志读取终止指标。
3. 保持相同域、案例和过滤条件，改成 `analytical` 再运行。解析残差把目标平移直接转换为末端参考修正；它给出本任务的有效参照。
4. 改成 `ppo_seed_0`，再比较种子1—4；同时记录成功、误差、接触、释放和停稳。查看训练回报与任务成绩各自表达什么，按失败判据找具体原因。
5. 改域为 `ood`，仍选案例0；观察更大目标平移下的变化。过滤开关采用同一域/案例配对，保留原始请求、实际残差和干预次数。

保存回放为固定ID案例0且过滤开启；实时3D使用你选择的域、案例和过滤。面板支持暂停回放、自己的新种子训练、停止并保留结果、打开原始结果和课程；训练进度在底部状态显示。训练期间先完成单次运行，参数修改在下一次新实验生效。MuJoCo窗口可通过鼠标调整相机；任务开始于9秒前缀末态，完整前缀有独立按钮和回放。

## 知识卡1 名义控制器与残差

名义控制器负责已经可靠执行的抓取、搬运、下降高度、夹爪和撤退动作。学习策略负责输出两维XY修正，末端参考为 `p_ref=p_nom+[Δx,Δy,0]`，逆运动学再计算七关节参考。这样每个模块承担明确任务，便于定位失败：名义轨迹、修正量、逆运动学、伺服和接触各有记录。残差强化学习的原始方法把传统控制与学习修正组合起来；本课是使用PPO的教学实现，控制对象为笛卡尔位置参考。[残差强化学习论文](https://arxiv.org/abs/1812.03201)

具体算例：名义XY为(0.5,−0.19)m，目标更新为(0.54,−0.214)m，所需残差为(+0.04,−0.024)m。归一化动作(0.5,−0.3)乘0.08m，得到这两个修正量。七个关节角根据新末端参考由IK求出，夹爪仍按固定阶段执行。你的验收是从代码指出这四种量分别处在哪个接口。

## 知识卡2 任务如何制造学习需求

原机械臂已经能沿固定目标完成搬运放置，本课在搬运完成后更新目标位置。ID目标在原目标周围平移40—65mm，OOD平移75—95mm，方向按重置种子生成。零残差继续沿旧目标执行；解析残差利用已知位移；PPO依据观测学习修正。该任务优先检验目标条件化和接口组合，复杂摩擦、未知动力学和视觉误差需要独立扰动任务。

严格问题：解析残差已经直接知道目标平移，这里使用强化学习的价值是什么？本课价值是学习环境接口、残差训练与科学对照；当前成绩按实际结果比较。研究候选可加入无法直接解析的接触偏差、观测延迟或滑移恢复，并保持信息权限和预算一致。每次新增因素都冻结新协议，保留原任务作为回归参照。

## 知识卡3 固定前缀与条件任务

前缀通过4500个0.002秒物理积分步执行原抓取搬运控制，末态必须有双指接触且物体高度大于0.38m。重置恢复 `mjSTATE_INTEGRATION`完整积分状态与IK规划状态，包含时间、速度和求解器相关状态；所有放置回合从同一个物理抓持状态出发。缓存只减少重复前缀计算，放置阶段每步仍执行真实动力学与接触。目标变化与重复训练种子提供的是条件放置证据，多抓取初态和不同物体泛化单独评测。[MuJoCo状态接口](https://mujoco.readthedocs.io/en/3.2.5/APIreference/APIfunctions.html#mj-getstate)

## 知识卡4 27维观测

| 输入 | 维度 | 归一化与用途 |
| --- | --- | --- |
| 七关节角 / 七关节速度 | 14 | 各除以3，提供机械臂运动状态 |
| 新目标相对旧名义目标XY | 2 | 除以0.08m，提供目标平移 |
| 目标相对物体XY误差 | 2 | 除以0.08m，提供当前纠偏方向 |
| 物体高度 | 1 | `(z−.275)/.2`，区分悬空与桌面 |
| 物体在TCP局部坐标系的相对位置 | 3 | 除以0.1m，反映抓持相对位姿 |
| 左/右指接触标志 | 2 | 分别记录，辨识接触状态 |
| 上一步实际残差XY | 2 | 除以0.08m，解释变化率过滤器状态 |
| 阶段时间 | 1 | `steps/125`，识别固定放置与释放时序 |

位置和速度来自仿真器，策略使用目标平移和相对误差两种信息。TCP局部坐标使用 `R_tcpᵀ(p_object−p_tcp)`，坐标系一致后才能比较滑移。终端验收还读取接触和停稳的历史窗口，本课27维输入保留部分可观测性；历史编码按后续反馈课扩展。你应能解释删除目标、接触或上一残差各会影响什么，并提出单因素验证。

## 知识卡5 动作单位与过滤

两维策略动作范围[−1,1]，每轴乘0.08m得到请求残差。过滤开启时，每控制步每轴的实际残差最多改变0.008m，相当于参考修正每轴0.2m/s；关闭后直接使用请求残差。这个约束覆盖参考变化率，机械臂动力学、关节边界和接触稳定性继续由实际轨迹检查。每轴限幅形成XY方形范围，其向量范数最大值为约113mm；OOD目标部分方向会遇到单轴80mm边界。

## 知识卡6 逆运动学与位置伺服

Panda有七个臂关节，末端参考约束三维位置和固定朝下姿态，IK使用阻尼最小二乘与关节参考裁剪。规划用独立 `MjData`，物理 `MjData`通过 `mj_step`积分更新。前七个控制输入为关节位置参考rad，最后一个夹爪控制采用原模型0闭合、255张开接口。IK误差、参考速度、执行器力和接触分别影响真实运动，网络输出与关节参考之间有明确的控制链。

## 知识卡7 固定阶段与接触

本课在9—10.6秒下降，从11秒开始张开夹爪，12秒后撤退，到14秒终止并评估。物体由接触摩擦支撑，位置随物理积分演化；释放后受重力落到桌面。名义控制器提供高度和夹爪调度，PPO只修正XY。有效指接触采用法向力>0.01N阈值；记录左右指标志、相对位移与物体速度，能区分提前滑落、残留有效接触、错误放置和未停稳。

## 知识卡8 奖励与独立验收

每步奖励 `20×误差下降−10×当前XY误差−0.002×动作平方和`，完整成功额外加5，关节违规减5。稠密奖励在物体移近目标时提供学习信号；任务验收单独读取放置、接触、释放和停稳条件。5秒固定任务完成后产生task terminal，包含成功与失败，bootstrap按实际终止处理。人为停止窗口属于未完成演示，完整任务判据仍按125步检查。

## 知识卡9 PPO预算与验证

复用上一课从零实现的tanh高斯PPO，每批8环境×128步，默认每训练种子8192交互步，五种子共40960步。每控制步20个物理子步，额外披露名义IK调用与固定前缀成本；前缀缓存和解析控制器属于可用资源。验证用4个重置，只按验证成功率减平均误差选择检查点；ID与OOD各8个重置分别留出。相同8个ID场景在五个训练种子上重复评测，场景数和训练重复数分别统计，正式扩展评测增加新场景与预算。

## 知识卡10 验收的七个条件

| 条件 | 判据 | 失败定位 |
| --- | --- | --- |
| 放置位置 | 末1秒平均XY误差≤35mm | 对照原始误差与目标位置 |
| 桌面高度 | 末1秒平均物体中心高度距.275m<15mm | 是否滑落桌面、仍悬空 |
| 停稳 | 末1秒平均线速度<.03m/s | 物体滑移、弹跳或接触振荡 |
| 释放 | 末1秒左右两指接触均消失 | 单指黏连或夹爪残留接触 |
| 运输接触 | 9—10秒双指接触比例≥90% | 大参考变化导致提前失持 |
| 相对滑移 | 9—10秒相对TCP漂移<40mm | 相对位姿和夹持稳定性 |
| 关节边界 | 全回合关节越界为0 | IK参考、执行偏差与边界 |

七项同时满足且完成125步才算成功。物体质量60g、边长50mm，桌面高度250mm，固定相机和固定朝下姿态属于当前配置。变化率过滤提供参考层约束，实机安全需要动力学、传感误差、碰撞和停止机制的专门分析。软件测试与哈希检查验证实现及记录，任务判据验证该配置的实际轨迹。

## 编程实操一 从动作追到物体

打开 `panda_residual_env.py`，沿 `step()`标出：策略动作 → 米制残差 → 变化率过滤 → TCP参考 → `Controller.ik` → 七关节参考 → 20次 `mj_step` → 物体误差。用动作(+0.5,−0.3)手算请求位移(+40,−24)mm；从零开始过滤后的第一步为(+8,−8)mm。在同一案例打开 `demos/analytical.csv`，核对请求和执行值。解释为什么实际物体XY位置包含伺服与接触误差。

## 编程实操二 单因素修改

先在面板保持8192步、种子5，点“训练自己的新实验”，完整结果写入 `outputs/panda-student/`。选一个因素，例如变化率限幅从8mm改为4mm；修改Config默认值，预先写出对接触、响应速度和放置误差的预测。使用全新目录按五种子、相同总交互预算与重置协议运行，保留源码快照和失败。成功阈值保持35mm，改成功判据作为独立任务协议登记。
