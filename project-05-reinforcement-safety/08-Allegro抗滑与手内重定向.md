# Allegro 抓持抗滑与手内重定向

本课练两件事。球受侧向拉力时，读出侧移并调整拇指参考。手腕固定时，用手指接触改变球的姿态，并在目标附近保持。两项共用同一掌面辅助抓持和准备动作，反馈规律、成功判据各自独立。

## 在本机看三组实验

1. 播放 [13 N 抗滑并排仿真](outputs/allegro-demos-20261128/pull13.gif)。左边 `hold` 保持指令，右边 `feedback` 根据侧移调整拇指。评估开始后 1.00 秒起施力，1.30 秒撤力。暂停在 1.30 秒读最近控制区间的力、侧移 `drift` 和拇指偏置 `thumb offset`。种子 5000000 的两侧读数约为 16.8 mm 与 9.9 mm，右侧偏置到达 −0.25 rad 限幅。
2. 播放 [重定向并排仿真](outputs/allegro-demos-20261128/reorient.gif)。左侧保持，右侧渐变拇指参考，观察球上红、绿、蓝三个轴标记和 `goal error`。两侧的手腕在评估期间固定，渲染标记跟随球的旋转，不参与碰撞或动力学。
3. 双击 `open_allegro_lab.cmd` 打开 MuJoCo，默认展示 `reorient/roll`。拖动视角从另一方向检查标记，等控制台打印评估结果后关闭 3D 窗口。使用同一启动器的命令参数可运行抗滑或失败组。已有项目02 Python 和项目03固定模型可直接复用。

## 知识卡 1　抓持同时依赖接触位置、夹紧力与摩擦

手指压球时，法向力沿接触面的法线方向，切向力沿接触面。单一点接触的库仑摩擦近似为 `‖fₜ‖ ≤ μ fₙ`。例如 `μ=1.5`、`fₙ=2 N`，切向力的理想上限为 3 N。多个接触方向不同，球要维持姿势还需同时满足力和力矩平衡。直接把各指的 `μ fₙ` 相加无法给出某一拉力方向的可承受上限。接触位置移动时，增大夹持指令也可能挤走球。用 `normal_force_n` 看各指和掌面，`contact_mu` 读求解器实际采用的切向系数。[MuJoCo 接触模型](https://mujoco.readthedocs.io/en/3.2.5/computation/index.html#contact) · [接触参数合成规则](https://mujoco.readthedocs.io/en/3.2.5/modeling.html)

## 知识卡 2　定义侧移和计算反馈

把世界坐标变到腕系，`p_rel = R_wristᵀ(p_obj − p_wrist)`。这套姿态下，世界 `+Y` 对应腕系 `−Y`。评估第 1 秒时锁存 `p_rel,y`，用 `d = p_anchor,y − p_rel,y` 表示向受力方向的位移。这里的侧移是物体中心相对手腕的位移。接触点滑动速度还要比较球和指尖在接触点的线速度与转动贡献，适合后续加入触觉观测的实验。

`slip_correction()` 计算 `Δq = −clip(K · (d − 0.001), 0, 0.25)`，默认 `K=28 rad/m`。若上一采样的侧移为 5 mm，拇指近端参考相对原值减小 `28×0.004=0.112 rad`。`q_ref_rad[13]` 对应 `thj1`。这个符号来自本抓持姿态的开发测量。反馈在 1.00–1.60 秒启用，撤力后继续观察 0.30 秒，然后回到固定参考。`feedback_input_m` 是动作前样本，`drift_y_m` 是同一行的动作后样本。

## 知识卡 3　手内重定向需要相对姿态目标

夹住球再转手腕，球的世界姿态会跟着变。这里固定手腕，用 `R_rel = R_wristᵀ R_obj` 衡量球在掌中的转动。目标从每次抓稳的初始姿态出发，在腕系绕归一化轴 `[-0.25, -0.49, 0.86]` 转 20°，`R_goal = R_delta R_rel,0`。轴和角来自开发轨迹附近的标定，用于一个局部目标。评估误差采用完整三维旋转角 `acos(clip((tr(R_goalᵀ R_rel)−1)/2,−1,1))`。相同转角绕另一根轴转动时仍可能误差很大。

`roll` 在约 0.70–1.40 秒把 `thj1` 的参考从 0.6 rad 平滑变到 0.2 rad，其余 15 个关节的参考保持。球的姿态随接触力矩变化，全程记录零外力、零外力矩与固定腕姿。`hold` 和 `reverse` 使用相同目标，分别保持参考和反向渐变。这里用开环指令实现一个已标定目标。下一次可尝试姿态误差闭环和多目标控制。

## 编程练习　只改抗滑增益

沿 `Hand.reset → Hand.pose → slip_correction → Hand.advance → assess` 追一行数据。先手算 `d=5 mm` 时 `K=14` 的偏置，应为 −0.056 rad。给 `test_correction_deadband_and_limit` 增加你的断言。再预测较低增益在 9、13、17 N 下的峰值侧移、限幅和接触。临界条件优先看逐种子数据。

```powershell
$Py = './project-02-urdf-mujoco-ros2/.venv/Scripts/python.exe'
$A = 'project-05-reinforcement-safety'
$Dest = "$A/outputs/allegro-student"
$Seeds = 5000010,5000011,5000012,5000013,5000014
& $Py -m unittest discover -s $A -p test_allegro_lab.py -v
& $Py "$A/run_allegro.py" run "$Dest/k28" --seeds $Seeds --gain 28
& $Py "$A/run_allegro.py" run "$Dest/k14" --seeds $Seeds --gain 14
& $Py "$A/run_allegro.py" verify "$Dest/k14" --report "$Dest/k14-replay.json"
```

首次复现公开实验用种子 `5000000–5000004`、增益 28、一个新的输出目录。`cases.json` 给逐回合指标，`trajectories.jsonl.gz` 每行存一个回合的 200 个样本。用 `gzip.open(path, 'rt', encoding='utf-8')` 逐行读，按 `task/mode/seed` 找两条轨迹。手算选一行的 `feedback_input_m` 和 `thumb_correction_rad`，再在 `actuator_force_nm` 中找对应执行器读数。参考角和实际输出力矩各有单位和用途。

## 验收方法

| 条件 | 如何验收 |
| --- | --- |
| 抓持 | 完成 200 步。球高 0.25–0.46 m，腕系中心相对初值的峰值偏移 ≤40 mm。地面和托盘均无超过 0.01 N 的承载接触 |
| 接触 | 至少 95% 样本有两根或以上手指，各指法向力和超过 0.03 N。最后 25 样本每帧均达标。掌面承载单独记录 |
| 固定手腕 | 全回合腕位置和旋转矩阵数值误差低于 `1e−10`。所有任务的外力矩为 0 |
| 抗滑 | 对照的力时序逐步相同，非零拉力连续 15 步。13 N 的冲量为 3.9 N·s。侧移绝对峰值 ≤14 mm，最后 25 样本绝对侧移均 ≤10 mm |
| 重定向 | 零外力、零力矩。最后 25 样本全都距离目标 ≤8°，并且相对起始姿态转过至少 12° |

个人验收提交四件证据：运行前的预测、自己的断言或源码修改、五个匹配种子的结果、一个抗滑或重定向回合的逐帧解释。解释要明确指出 17 N 下哪项失败，或者反向重定向为什么转了角度还失败。五个评测种子是环境重置，使用同一球、同一腕姿和窄扰动范围。本课范围为掌面辅助、固定腕部的局部操作。跨物体、带视觉的姿态估计、重新抓取和学习策略有独立验收。
