## 冻结实验设置

四个控制器共用模型、关节PD、力矩限幅、推力时序和重置种子，只改参考生成规则：

| 控制器 | 参考生成 |
| --- | --- |
| `fixed` | 恒定参考，无反馈 |
| `com` | `Δq_ankle = 12·e_com + 2.4·ė_com` |
| `com_no_damping` | 同上但去掉 `2.4·ė_com` |
| `wrong_sign` | `com` 的修正取反 |

`e_com = com_x − support_x − 0.05`（`support_x` 为左右踝关节中点）。推力在t=2.0s施加0.2秒，作用于骨盆质心：

| 场景 | 力 |
| --- | --- |
| `none` | 0N |
| `push_front` | +40N x |
| `strong_front` | +60N x |
| `push_back` | −60N x |
| `push_left` | +120N y |

留出重置为3000000–3000004；开发种子为0。初态为标定触地高度+小噪声（XY σ=1mm、高度 σ=0.5mm、关节 σ=1mrad、速度 σ=2mm/s），无预settle。

## 标定阶段的实际发现（已保留的负面与修正结果）

1. **固定提交的默认姿态不可用。** `h1.xml` 自带姿态（骨盆0.98m、髋−0.4、膝0.8、踝−0.4）要求髋到踝0.906m，而两条0.4m腿最多0.8m，双脚被压进地板约10cm，接触求解器把机器人弹出并翻滚。本课改用离线标定站姿：骨盆1.06279m、髋−0.20、膝0.45、踝−0.25。`H1Stand` 现在会校验这四个常量。
2. **踝关节力矩符号与教材直觉相反。** 实测 d(a_com)/d(q_ankle) = −2.85 1/s² per rad：踝参考越负，质心越向前加速。原因是这条腿链几何与脚掌形状（足底自踝关节向前0.154m、向后0.050m）使压力中心随负向踝旋转前移。第一版控制律按直觉写正号，结果四控制器全部在1秒内后倒；改正符号后才出现可用的对照。
3. **开环站姿本身不稳定。** 质心仅比踝关节中心靠前约1.6mm，接近支撑区间后缘；固定参考在无扰动下约1.4秒后倒，调高PD增益无效。
4. **髋横滚反馈无贡献。** 侧向误差改善小于3mm，侧向失败阈值变化0N，最终无任何用例使用它。
5. **重置噪声必须收窄。** 关节噪声±3mrad、速度±10mm/s时，固定参考与反馈控制器都会在反馈启用前被推翻；收窄到±1mrad、±2mm/s后 `com` 通过5/5。这是能力边界，不是可以省略的细节。

## 稳定性边界（开发种子，冻结前测得）

| 控制器 | 60N前推 | 80N前推 | 120N侧推 | 140N侧推 | 无扰动 |
| --- | --- | --- | --- | --- | --- |
| `fixed` | 失败 | 失败 | 失败 | 失败 | 失败 |
| `com` | 通过 | 失败（踝力矩饱和） | 5/5通过 | 1/5通过 | 通过 |

侧推场景从150N下调到120N的原因：150N下 `com` 有4/5案例仅因“短暂失去双脚支撑”而失败，而质心误差与恢复时间均满足；140N实测1/5通过，说明120N已贴近边界且判据仍可评分。该下调在冻结前完成，判据本身未放宽。

## 待验证假设与后续

- H1行走、落脚点规划与踏步恢复未实现，需要独立的观测/奖励与验收协议。
- 复杂地形、推力序列、变质量与观测噪声下的恢复边界未测。
- 学习残差恢复（在解析反馈上叠加RL）未训练：是否需要RL、能带来多少边界提升，是本课之后要检验的假设。
