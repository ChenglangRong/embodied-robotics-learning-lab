# 第1课：专家怎样变成可学习的数据

学习目标：你能给每一条数据说明“动作执行前看到了什么、输出什么、下一步发生什么”，并能解释单步预测和闭环执行各自测量的内容。

## 1. 定义契约

复用项目01二连杆环境。DLS控制器充当专家，学习策略以后用相同函数入口替换专家。

观测：`o_t = [sin(q1), cos(q1), sin(q2), cos(q2), goal_x-x, goal_y-y]`，共6维。正弦/余弦表达关节周期性，目标误差让策略具有目标条件。动作：`a_t = [qdot1, qdot2]`，单位rad/s，限幅为环境配置的±2 rad/s。该低维环境用关节速度推进运动学，没有惯性或接触状态。

数据：`(episode_id, step, o_t, a_t, o_next, success, timeout)`。同一episode的相邻时刻高度相关，完整episode需要属于同一划分。下一层Panda环境将增加动态状态与夹爪/接触信息。

## 2. 正确的收集顺序

以下示例演示一条完整轨迹的收集契约；对应实现位于本项目 `learning.py` 的 `encode()` 和 `collect()`，可通过图形面板的“收集专家示范”运行：

```python
import numpy as np
from robot_lab.planar_arm import Config, TwoLinkReachEnv, dls_action

def encode(env):
    q = env.q
    return np.r_[np.sin(q[0]), np.cos(q[0]),
                 np.sin(q[1]), np.cos(q[1]), env.goal - env.position()]

env = TwoLinkReachEnv(Config())
env.reset(seed=11, goal=(0.55, 0.55))
episode = []
for step in range(env.cfg.max_steps):
    obs = encode(env).copy()                 # 动作执行前的观测
    raw_action = dls_action(env)
    action = np.clip(raw_action, -env.cfg.velocity_limit, env.cfg.velocity_limit)
    _, _, done, info = env.step(action)
    episode.append({"step": step, "obs": obs, "action": action.copy(),
                    "next_obs": encode(env).copy(),
                    "success": info["success"], "timeout": info["timeout"]})
    if done:
        break
```

项目01旧CSV记录更新后的关节角与刚执行的动作。训练数据需要明确动作前的观测；按上述顺序重新收集，或显式重建观测时序。数据对齐测试应核对 `next_q ≈ q + dt*action`。

动手要求：写出前3行的obs/action形状和单位；说明截断前动作与真正执行动作分别适合什么训练目标。当前设计学习环境实际执行的限幅动作，原始专家请求另存用于诊断。

## 3. BC目标与闭环差异

行为克隆最小化 `mean(||π_theta(o_t)-a_t||²)`。teacher-forced评测将专家访问的观测输入策略，衡量这些状态上的动作误差；闭环评测把策略输出送进环境，下一步再读取策略自身造成的状态。

小动作偏差可能改变接下来的状态分布，并在长序列中累积。DAgger在策略自己访问的状态查询专家、聚合新数据，用来扩展纠正覆盖。理论结论依赖相应假设；实际神经网络训练需要独立闭环评测。[原论文](https://arxiv.org/abs/1011.0686)
