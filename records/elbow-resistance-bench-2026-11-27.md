## 第一版台架

夹紧上臂板，将竖直铰轴装在板端，让模拟前臂的轻杆在水平面内往复。在距轴 0.20 m 处安装测力连接点，推拉方向始终垂直杆件。使用对称可调摩擦铰链、独立角度尺或编码器、带牛顿读数的双向推拉力计及接触温度计。准备低摩擦自由轴和一根弹力带作对照。纯机械摩擦在屈、伸程均耗能；哑铃回落有屈肌离心控制，弹力带回程会释放储能。选择摩擦方案意味着研究屈伸肌交替主动发力的轻阻练习。铰链厂商的额定值及压紧螺钉的位置需要用外部力计校准。[可调铰链系列及规格](https://media.southco.com/media/static/Literature/e6-at.en.pdf)

1. **校准与空载。** 记录实际力臂、推拉力计零点及分辨率，用已知参考力检查正负两方向。换用低摩擦自由轴测空载底噪。竖直转轴消除杆件自重绕该轴的力矩；缓慢匀速的中段用于估算阻力，启停段单列。20 cm 力臂下，3、6、9 N 对应 0.6、1.2、1.8 N·m，均为拟定台架值。建议推拉力计分辨率不劣于 0.1 N，约相当于此力臂下 0.02 N·m，测量不确定度还取决于校准和力臂。
2. **档位与方向。** 机械行程设为 40°–110°。从 1.2 N·m 开始；每档至少五个往返，一个条件一个 CSV。按屈肘角增加为正，从录像或同步记录分别读出屈、伸经过 45°、60°、75°、90°、105°时的有符号切向推力。伸程按对应角度填入同名列。外力朝屈肘方向为正，手施力或电机施力均沿同一约定，保留符号。分别做约 30°/s 和 60°/s 的匀速组，保留全程的原始时间、角度、力和温度。手动运动可用视频复核速度；采样无法解析启动峰时，单列慢增力启动试验，峰值结论限定在仪器带宽内。
3. **热漂与重装。** 中档连续 100 个往返，每 10 个记录外壳温度与实际用时。比较最初与最后五次的中段力矩。冷却后松开重调到同一刻度，至少三次，每次五个往返。记录左右两个方向，防止一侧漂移被平均掩盖。
4. **弹力带公平比较。** 在同一假肘两侧记录锚点、初长和预紧，调到屈肘程在 45°–105°区间的正向输入功与中档尽量匹配，目标差不超过 10%。校准完成后固定设置，比较两方向曲线及回程有符号机械功。装置总阻力是报告主值，空载曲线另列。弹力带的实际阻力同样从末端切向力测得，不能把带张力直接乘以杆长。
5. **工程去留。** 以下是本次提出的初版目标。在 1.2 N·m 档，每次重新装调的两个方向中段力矩中位数均落在 1.08–1.32 N·m，三档按实测值有序且各档重复测试的中位数区间互不重叠。100 圈前后同向中段力矩漂移不超过 10%，慢启动峰不超过同档同向稳态力矩的 1.5 倍。任何一项持续失败，先检查测量误差、摩擦副、预紧或散热，再决定是否制作袖套。温升记录用于比较设计；人体接触条件与温度限值需另行评估。

### 记录与计算

从仓库根目录运行下面的命令。第一行创建五个往返的空白表，文件已存在时会保留原文件。按一个装置、速度、温度阶段、重装编号各存一份，文件名标明条件。

```powershell
python tools/elbow_bench.py brake_mid_cold_mount1.csv --template
# 填完五个角度的实测切向力后执行
python tools/elbow_bench.py brake_mid_cold_mount1.csv --radius-m 0.20
python -m unittest discover -s tools -p test_elbow_bench.py -v
```

脚本输出每个方向的中段阻力矩中位数、单程输入功中位数和五个角度各自力矩中位数的最大值与最小值之差。用最后一项核验阻力是否在某些角度过大，即使总功相当也要逐角度比较。输入功按梯形公式积分，覆盖 45°–105°。理想中档持续 1.2 N·m，测量窗口每程应为 1.2 × π/3 ≈ 1.257 J。摩擦模型的两程均需输入正功；弹性回程的负输入功表示装置向外返还能量。五个取样点只用于匀速中段计算，启动峰与温升应从独立原始记录取得。正式计算人体训练量还需考虑姿态、惯性、错位和软组织运动。

### 从铰链推进到穿戴

第二阶段将两条连杆固定在带软包层的假上臂与假前臂，在假肘自身的转轴上测力矩，分开记录铰链轴和假肘轴的角度。每次重新绑紧后，在同档下测传给假肘的力矩、绑带滑移和机械活动范围，比较固定绑带和带可重复定位标记的绑带。仅当台架结果可复现，再和组内人员讨论低负荷穿戴、快速解除、接触压力与伦理审批。与弹力带做交叉试用时记录准备时间、舒适度、能否复现上次负荷、是否自愿再用；付费需求与长期力量增长应分别研究。

## 同一台设备，个人与机构怎样验收
