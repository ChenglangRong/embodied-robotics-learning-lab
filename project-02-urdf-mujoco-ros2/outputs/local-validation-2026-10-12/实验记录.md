# 项目 02：Windows 本机仿真实验记录（2026-10-12）

## 范围与环境

- 源码基点：Git commit `e12850c`；URDF SHA-256：`a54c0dcaad922673d732ef741927d2310654ca5a77c30d9769e737ca3277682b`。
- Windows 11，Python 3.12.4，MuJoCo 3.2.5；项目独立 `.venv` 的依赖见 `requirements.txt`。

## ROS 2 环境部署状态

当前 Windows 会话原本没有 ROS 2 命令或已注册的 WSL 发行版。用户授权后，管理员运行 `wsl.exe --install --no-distribution` 返回退出码 0；系统现有 WSL 包且显示重启待完成。Ubuntu 24.04 安装包已下载校验，应用包注册长时间没有完成，已结束该次安装尝试；当前尚未核实 Ubuntu 发行版可启动。Windows 重启并完成 Ubuntu 用户初始化后，才能执行 ROS 2 Jazzy 安装与桥接运行验收。系统重启由用户手动进行。
